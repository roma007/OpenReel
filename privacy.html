OpenReel 隐私政策

最近更新：2026-10-23 · 开发者：蒙锋

一、核心声明

OpenReel 是一款纯客户端视频聚合应用，不设账号体系、不收集任何可识别您个人身份的信息。所有数据仅存储于您的设备本地，默认不会上传至任何服务器。

二、信息收集与使用

本应用不收集以下任何信息：

  • 真实姓名、昵称、手机号码、电子邮箱
  • 身份证号、银行卡号、付款记录
  • 地理位置、通讯录、相册、麦克风、摄像头
  • 设备 IMEI、MAC 地址、广告标识符（OAID / IDFA）
  • 浏览器历史、其他应用列表、剪贴板内容

本应用在本地存储的信息（仅存于您的设备，默认不上传）：

  • 您主动添加的视频源地址
  • 媒体元数据、收藏、播放历史、播放进度
  • 应用偏好设置（主题、字号、播放策略等）

三、运行时权限说明

Android 系统在功能需要时会申请以下权限。除下列说明外，权限不会被用于任何其他目的。画中画（Picture in Picture）使用 Android 系统多窗口能力实现，不需要也不申请悬浮窗权限。

android.permission.INTERNET
访问网络。
用途：向您配置的视频源服务器发起 HTTP/HTTPS 请求，获取节目列表与视频流。本应用的所有网络请求仅指向您主动添加的视频源地址，不向开发者自有服务器发送请求。
android.permission.VIBRATE
震动反馈。
用途：部分交互（长按、确认）时的轻量反馈，不主动触发。
android.permission.READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE（Android 12 及以下）
读写外部存储。
用途：导出/导入收藏与源配置文件、调试日志导出。Android 13 及以上版本已自动拆分为更细粒度的权限，无需额外申请。
android.permission.REQUEST_INSTALL_PACKAGES
安装应用。
用途：应用内检查到新版本并下载 APK 后，调起系统安装器完成升级。系统会弹出明确的二次确认。

四、第三方库与 SDK

本应用基于以下开源组件构建：

  • React Native（MIT）— 跨平台 UI 框架，由 Facebook 维护，运行时不收集任何数据
  • Expo（MIT）— 开发工具链，本应用已禁用 Expo 更新服务，不向外发送遥测数据
  • SQLite / expo-sqlite（公有领域）— 本地数据库，所有数据仅写入本地 .db 文件
  • dav1d（BSD）— AV1 视频解码器，纯本地计算

本应用不包含任何第三方广告 SDK、数据统计 SDK 或崩溃上报 SDK。

五、数据存储与保护

  • 所有数据存储于应用私有目录（Android: /data/data/com.openreel.android/；iOS: App Sandbox），默认仅应用自身可读写
  • 卸载应用会一并删除全部本地数据，无法恢复
  • 应用未实现数据同步功能，您更换设备时需手动导出再导入

六、用户权利

  • 查看：应用内「关于我们 → 数据导出」可将收藏与源配置导出为 JSON 文件
  • 删除：应用内「设置 → 清理数据」可选择性清除播放历史、收藏、任务记录，或完全重置数据库
  • 停止：卸载应用即可终止一切本地数据处理
  • 反馈：有隐私相关疑问可通过文末联系方式提出

七、儿童保护

本应用不针对 14 周岁以下儿童，也不会刻意收集儿童的任何信息。应用中不包含面向未成年人的广告或诱导付费内容。

八、政策更新

本隐私政策可能随版本迭代更新，重大变更会在应用内设置页弹窗提示。您可随时在应用内「关于我们」页面查看最新版本的本政策。
